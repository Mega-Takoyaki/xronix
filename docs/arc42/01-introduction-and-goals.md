# はじめに と 目標

## 要求の概要

@example_accountに付く返信・メンションを拾い、分類し、返信案を作り、本人が承認したものだけを送信する。

## 実測した現状（2026年10月時点）

| 項目 | 値 |
| --- | --- |
| 直近50投稿の返信数 | 平均1.7件／投稿（最大14） |
| インプレッション | 69〜7,905／投稿 |
| メンション | 直近約8日で13件（約1.6件／日）、それ以前は月数件。ユニーク31人 |
| アカウント | blue、公開。成人向け投稿はXでは行わず Fanvue で行う。宣伝素材を投稿し、メディアは投稿ごとにセンシティブ指定 |

この量なら、個人1人が1日数分で処理できる。性能要件は実質的に無い。重視するのは、取りこぼしの無さ、二重投稿の無さ、アカウントを危険にさらさないことである。

## 品質目標

| 優先 | 目標 | 具体 |
| --- | --- | --- |
| 1 | 二重投稿をしない | 投稿作成は一切リトライしない。送信前に状態を条件付き書き込みで確定する |
| 2 | アカウントを守る | 1日の送信上限、ブロック対象一覧、緊急停止、リンクを入れない |
| 3 | 取りこぼさない | since_id による差分取得、取得済みIDの保存 |
| 4 | 低コスト | 月額おおむね数ドル以内。NAT Gateway等の固定費を避ける |
| 5 | 1人で保守できる | 構成要素を少なく保つ。IaCで再現可能にする |

## ステークホルダー

| 役割 | 関心 |
| --- | --- |
| 運用者（アカウント所有者・1人） | 返信の確認と承認だけに時間を使う。余計な確認機能は不要 |

## 非目標

- 不特定多数への一斉・定型の自動返信（スパム判定・凍結の原因）
- 成人向けの内容の取り扱い（ReelMillyと用途を分離する）
- 複数アカウント・複数ユーザー対応
