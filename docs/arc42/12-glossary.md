# 用語集

| 用語 | 意味 |
| --- | --- |
| メンション | 自分のアカウント宛て（@GirlAidol を含む）の投稿。返信も含む |
| 返信案 | システムが作る、返信の候補文 |
| 承認 | 運用者が返信案の送信を許可すること |
| since_id | 取得済みの最新ID。これより新しいものだけを取得するための値 |
| 緊急停止 | 取得と送信を止める設定のフラグ |
| ブロック対象一覧 | 返信しないユーザーの一覧。Xのブロックとは別の、本アプリ内の一覧 |
| リース | トークン更新の排他制御のため、期限付きで取る更新権 |
| ADR | Architecture Decision Record。設計判断の記録 |
