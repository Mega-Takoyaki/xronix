# ADR-0011 AIの既定を Amazon Bedrock にし、OpenAI も選べるようにする

状態: 採用　日付: 2026-10-12　置き換え: ADR-0002 の「外部LLMを使わない」部分

## 背景

当初は、成人向けの文脈を含む可能性があったため、Claude（Bedrock含む）には送らない方針だった。運用者から、本アプリでは成人向けの内容を扱わない（ReelMillyと用途を分離する）ことが示された。前提が変わったため、方針を改める。

## 決定

| 方式 | 位置づけ | 認証 |
| --- | --- | --- |
| Amazon Bedrock | 既定 | AWSのIAM。APIキーは不要 |
| OpenAI（互換API） | 任意 | APIキー（SSM） |
| AIを使わない | 任意 | なし（ルールのみ） |

- AIの役割は、①メンションの分類 ②返信文の生成。②は、ルールのアクション「AIで作る」で、ルールごとに指示と文脈を設定する（ADR-0014）。リンクが含まれる、または長すぎる返信文は、使わない。
- ルールでスパム・要注意と判定したメンションは、AIに送らない。費用と外部送信を減らし、判断を保守的に保つため。
- AIの呼び出しに失敗したら、ルールの判定に戻す（取得処理は止めない）。
- Bedrockの呼び出しは、AWS SDK（boto3）の Converse API で行う。追加のライブラリを同梱せず、Anthropic以外のモデルIDにも使える。モデルIDとリージョンは画面で変更できる。
- ローカルのモックモードでは、外部のAIを呼ばない。
- 本アプリでは、成人向けの内容は扱わない。

## 既定のモデルID

モデルは、画面で、使える一覧から選ぶ。未選択（自動）なら、安価な小型モデルを自動で選ぶ（ADR-0015）。

## 結果

- Bedrockの利用には、AWSコンソールでのモデルの利用有効化が必要になる場合がある。
- Lambdaのロールに `bedrock:InvokeModel` を付与した。
- 費用は、月100件程度の分類なら数セント以内の見込み（推測）。
