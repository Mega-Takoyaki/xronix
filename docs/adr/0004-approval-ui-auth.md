# ADR-0004 承認画面の認証にCognitoを使う

状態: 保留（当面はBasic認証。ADR-0010）　日付: 2026-10-12

## 背景

承認画面は公開URLに置く。送信できる強い権限を持つため、1人用で堅い認証が必要。

## 選択肢

| 案 | 長所 | 短所 |
| --- | --- | --- |
| Cognito User Pool（1ユーザー、サインアップ無効、MFA有効） | マネージド、HTTP APIのJWTオーソライザーと直結、無料枠内 | 設定項目が多い |
| 独自の共有秘密＋Lambdaオーソライザー | 構成が単純 | 自前の認証。漏えい時の対策が弱い |
| CloudFront署名＋IP制限 | 単純 | IPが変わる環境に弱い |

## 決定（提案）

Cognito User Pool。サインアップを無効にし、運用者のみを管理者作成で登録し、MFAを有効にする。独自ドメインは使わず、標準のHosted UIまたはSDKでログインする。

## 結果

- 費用は無料枠内の見込み。
- ログイン画面の日本語化は、Hosted UIでは限定的。自前のログインフォームにするかは実装時に決める。
