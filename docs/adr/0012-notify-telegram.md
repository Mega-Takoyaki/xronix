# ADR-0012 通知は Telegram にする

状態: 採用　日付: 2026-10-12　置き換え: ADR-0005

## 決定

通知は Telegram Bot API で行う。Discord、メール、LINEは実装しない。

- ボットトークンは SSM（SecureString）に、チャットIDと任意の画面URLは設定に置く。
- 通知には「承認待ちN件」と、設定されていれば画面のURLだけを載せる。返信の本文は載せない。
- 画面から「テスト送信」ができ、失敗時は Telegram の返す理由を表示する。トークンはログにも画面にも出さない。

## 理由

運用者の指定。設定が少なく、無料で、スマホに即時に届く。
