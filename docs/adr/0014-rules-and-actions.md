# ADR-0014 反応の種類ごとに、実行するアクションをルールで設定する

状態: 採用　日付: 2026-10-12

## 背景

メンションへの対応を「返信案を作って承認」だけに固定せず、反応の種類ごとに、いいね、AIの返信、通知など、実行する処理を運用者が設定できるようにしたい。自投稿の反応数が基準を超えたときの、追加コメントも対象にしたい。

## 決定

### 反応の種類（イベント）

| 種類 | 判別の方法 | 追加のAPI呼び出し |
| --- | --- | --- |
| 自分の投稿への返信 | メンションが返信で、返信先の作者が自分、返信先が会話の最初の投稿 | なし |
| 自分の返信への返信（スレッドの続き） | 同上で、返信先が会話の最初の投稿ではない | なし |
| 自分の投稿の引用 | メンションに含まれる、引用（`quoted`）の投稿 | なし |
| その他のメンション | 上のどれでもないもの | なし |
| 自投稿の数値が基準以上 | 自分の投稿の `public_metrics`（いいね、リポスト、返信、引用、インプレッション）が基準以上 | 自分の投稿の読み取り（設定の間隔ごと） |

### ルール

- ルール = 反応の種類（複数可）＋ 分類（任意）＋ アクションの並び。上から順に見て、最初に合った1件だけを実行する。何も合わなければ、人が確認する「承認待ち」に入る。
- 自投稿の数値のルールは、ルールごとに独立。各投稿で、基準を初めて超えたときに、1回だけ実行する（ルールIDと投稿IDで重複を防ぐ）。
- 初期のルールは、従来の動き（スパムは記録のみ、要注意・その他は人が書く、ポジティブ反応・質問は定型文の返信案）と同じ。見本として、無効の2件（ポジティブ反応へのいいね、いいね100件超えのAIコメント）を入れる。

### アクション

| アクション | 内容 | 補足 |
| --- | --- | --- |
| 何もしない | 履歴に記録のみ | |
| 通知 | Telegramに、反応の種類だけを通知 | 本文は載せない |
| いいね | 相手の投稿にいいね | 権限 `like.write` が必要。1日の上限あり |
| 返信案を承認待ちに入れる | 定型文／AI／空欄から選ぶ | 人が確認して送る |
| 承認なしで送信 | 定型文／AIから選ぶ | 下の安全装置が効く |
| ブロック対象に追加 | このアプリ内の一覧に追加 | Xのブロックとは別 |

- AIで返信を作る場合は、指示（プロンプト）と、文脈（この投稿だけ／スレッドの流れも渡す）を、ルールごとに設定する。スレッドは、返信先をたどって、1〜10件まで遡る。
- 自投稿の数値のルールでは、いいね・ブロックは使えない（相手が自分のため）。返信は、自投稿へのスレッド（追加コメント）になる。
- 1つのルールに、返信のアクションは1つまで。1つのアクションが失敗しても、残りは続ける。

### 安全装置

- AIの入力には、他人の投稿（信頼できない入力）が含まれる。投稿内の指示に従わされるのを完全には防げないため、AIの出力は、リンク・`@`・`#`・長すぎるものを、すべて捨てる。捨てた場合は、人が書く。承認なしの送信（`send_reply`）をAIと組み合わせる場合は、このリスクを承知のうえで使う（既定は承認制）。

- 承認なしの送信は、1日の自動送信の上限（既定5件）、全体の送信上限、緊急停止、ブロック対象、リンク禁止の検査を通る。上限に達したときや、返信文を作れなかったときは、送らずに承認待ちに回す。
- いいねは、1日のいいね上限（既定20件）がある。失敗したときは、上限に数えない。
- 投稿作成は、再試行しない（ADR-0006）。結果不明は、自動で再送しない。

## 費用

| 項目 | 単価・見込み |
| --- | --- |
| 自投稿の読み取り（数値のルール） | 約$0.001／投稿。例: 6時間ごと・20投稿で、1日約$0.08（月約$2.4）。数値のルールが1つも有効でなければ、読まない |
| スレッドの文脈 | 遡った件数ぶんの読み取り（1件あたり最大約$0.005の見積もり） |
| いいね、返信の送信 | 料金区分は未確認。返信は投稿作成と同額（$0.015）と仮置き |

## 限界（既知）

- 他人によるリポスト（引用なし）は、取得する手段が無い（高額になるため扱わない）。「引用」は、メンションに含まれるものだけを拾う。引用の網羅的な取得は、将来の課題。
- 数値のルールは、設定した期間（既定7日）に投稿した投稿が対象。有効にした時点で、すでに基準を超えている投稿にも、1回動く。
- いいねの権限 `like.write` を追加したため、すでにXと接続している場合は、再接続が必要。
