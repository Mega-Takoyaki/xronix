# ADR-0018 同じ相手との会話に上限を置く

状態: 採用　日付: 2026-10-18

## 背景

同じ相手が返信を繰り返す場合や、相手も似た自動返信の仕組みを使っている場合、返信が返信を呼び、会話が際限なく続く。送信の費用がかさむだけでなく、スパムとみなされる恐れがある。

## 決定

| 上限 | 既定 | 数え方 |
| --- | --- | --- |
| 同じ相手との、同じ会話での返信 | 3回 | 会話ID＋相手のユーザーIDが同じ、送った・送信中・送信待ちの返信 |
| 同じ相手への、1日の返信 | 5回 | 相手のユーザーIDが同じ、今日（日本時間）の返信。会話をまたいで数える |

- 範囲は、どちらも1〜50（上限なしにはできない。安全装置のため）。設定の「安全装置」で変える。
- 上限に達したら、ルールによる返信案づくり（定型文・AI）と、自動送信を止める。AIを呼ばないので、費用もかからない。反応は「履歴」に残り、アクションの結果に理由が出る。
- 人が承認する送信は、止めない（運用者の判断を優先）。
- 自投稿の数値のルール（投稿者が自分）には、適用しない。

## 結果と制約

- 数えるのは、このアプリが送った返信だけ。Xの画面から、手で返信した分は数えない。
- 相手が別のアカウントに切り替えた場合は、別人として数える。
